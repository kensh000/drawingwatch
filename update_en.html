In Development / Planned Features

The Drawing Watch app itself is currently in development.

For an overview of the features planned for the initial release, please visit Top .

The following features are not planned for the initial release, but may be added in future version:

  • Option to switch the UI elements between left- and right-handed layouts
  • Ability to change the canvas size
  • Color selection from RGB and HSL color palettes
  • Improved search functionality within the Help tab
  • Reduced power consumption
